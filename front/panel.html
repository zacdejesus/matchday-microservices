Se comprueba solo cada 5 segundos.

Cómo arrancar todo

  1. Abre una terminal por servicio, todas dentro de la carpeta matchday-microservices.
  2. Datos (Django): 
    cd datos
pip install django
python manage.py runserver 8001
  3. Decisión (FastAPI): 
    cd decision
pip install -r requirements.txt
uvicorn main:app --port 8002 --reload
  4. Puerta (Flask): 
    cd puerta
pip install -r requirements.txt
API_KEY=una-clave-local python app.py
    (la clave tiene que coincidir con la del campo X-API-Key de arriba)
  5. Este panel: 
    python front/servidor.py
    y abre http://localhost:8080.
  6. Cuando las tres tarjetas de arriba estén en verde, pulsa Probar todo o ve paso a paso.

Pasos para probar
